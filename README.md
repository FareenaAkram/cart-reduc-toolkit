# Cart Redux Toolkit

A shopping cart implementation built to practice global state management using **Redux Toolkit** — covering slices, actions, and connecting React components to a centralized store.

## Built With

![React](https://img.shields.io/badge/React_18-61DAFB?style=flat-square&logo=react&logoColor=black)
![Redux Toolkit](https://img.shields.io/badge/Redux_Toolkit-764ABC?style=flat-square&logo=redux&logoColor=white)

- **React 18** — UI components
- **Redux Toolkit** — global state management (cart items, quantities, totals)
- **React Redux** — connecting components to the store
- **React Testing Library** — component testing

## Features

- Add/remove items from cart
- Update item quantities
- Real-time total calculation
- Centralized cart state managed via Redux slices

## Getting Started

```bash
# Clone the repo
git clone https://github.com/FareenaAkram/cart-reduc-toolkit.git
cd cart-reduc-toolkit

# Install dependencies
npm install

# Run locally
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## About This Project

This project was built specifically to practice Redux Toolkit fundamentals — slices, reducers, and `useSelector`/`useDispatch` — as part of my advanced React learning path. See also [`Shopping-Cart-Project`](https://github.com/FareenaAkram/Shopping-Cart-Project), which solves the same cart problem using React's Context API, for comparison between the two state-management approaches.
